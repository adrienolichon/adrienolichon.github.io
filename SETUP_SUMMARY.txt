1️⃣  CRÉER LA TABLE SUPABASE
    → Allez dans SQL Editor de Supabase
    → Exécutez sql-setup.sql
    → Vérifiez que 4 lignes sont insérées

2️⃣  TESTER LA CONNEXION
    → Ouvrez wishlist-test.html
    → Testez "Connexion", "Charger", "Insérer"
    → Tous les tests doivent être ✅

3️⃣  TESTER SUR VOTRE SITE
    → Ouvrez wishlist.html
    → Cliquez sur "Marquer comme acheté"
    → Vérifiez la classe .purchased

4️⃣  TEST MULTI-NAVIGATEURS
    → Ouvrez dans 2 navigateurs
    → Cliquez dans l'un, rafraîchissez l'autre
    → Vérifiez que ça se synchronise ✅

5️⃣  METTRE EN LIGNE
    → git add .
    → git commit -m "feat: add Supabase wishlist sync"
    → git push origin main
    → Attendez 1-2 min que GitHub Pages se mette à jour
